\# API 参考



以下接口仅用于文档展示，不提供真实服务。



\## 查询文档列表



\- 请求方法：GET

\- 请求路径：/api/docs

\- 功能：返回文档条目列表。



\### 返回示例



```json

{

&#x20; "items": \[

&#x20;   {"id": 1, "title": "使用指南"}

&#x20; ]

}

```



\## 查询单篇文档



\- 请求方法：GET

\- 请求路径：/api/docs/{id}

\- 功能：按 id 返回单篇文档详情，id 不存在时返回 404。



\### 请求参数



| 参数 | 类型 | 必填 | 说明 |

| --- | --- | --- | --- |

| id | int | 是 | 文档编号，写在路径中 |



\### 返回示例



```json

{"id": 3, "title": "使用指南", "updated": "2026-11-04"}

```
