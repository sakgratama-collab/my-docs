\# 关于本项目



\## 项目目标



实现从 Markdown 文档到公开网站的自动化发布。



\## 技术组成



| 工具 | 作用 |

| --- | --- |

| Markdown | 编写文档内容 |

| MkDocs Material | 将文档构建成静态网站 |

| GitHub Actions | 自动执行安装、构建和部署 |

| GitHub Pages | 托管并提供网站访问地址 |



\## 各部分之间的关系



docs 目录里的 Markdown 是我手写的"源码"；MkDocs 把它们构建成 site 目录下的静态网页"成品"；GitHub Actions 是云端机器人，在我推送后自动完成构建和上传；GitHub Pages 负责把成品挂到公网上供人访问。site 目录由机器生成，所以写进 .gitignore，不提交到仓库。



\## 我的实践体会



自动化部署把容易出错的构建、发布环节固定在工作流配置里，人只负责内容本身，这就是"把重复劳动交给机器"的工程思路。
